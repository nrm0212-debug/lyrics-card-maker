## Data persistence and recovery
The browser application uses `localStorage` (per origin and browser/device):
- `lyricsCardMakerDraftV1`
- `lyricsCardMakerLibraryV1`
- `lyricsCardMakerCurrentSongV1`

The app's **「バックアップ」** button exports a full JSON backup with `app: "lyrics-card-maker"`, `version: 1`, `currentSongId`, and `library`. **「復元」** imports that backup and **replaces the browser's current library**. Never import on the original iPhone without independently protecting its current data first. The separate **担当用 JSON** workflow (`lyrics-card-maker-role-work`) is not a full-library backup.
